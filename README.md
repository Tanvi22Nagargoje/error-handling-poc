# Error Handling in Next.js - Proof of Concept (POC)

This is a proof of concept (POC) project demonstrating error handling in a Next.js application. It includes handling both server-side and client-side errors, showing how to display custom error pages and use error boundaries.

## Features
- **Custom Error Pages**: A custom 404 page for "Page Not Found" errors and a custom 500 page for server-side errors.
- **Error Boundary**: A React error boundary component to catch errors in the component tree and display a fallback UI.
- **Manual Error Trigger**: A button to manually trigger errors for testing purposes.
- **API Error Handling**: A mock API endpoint that simulates both successful and failed data fetches.
